# Security

Please report a vulnerability in these packages, or in the Tuix service, by email to
security@tuix.app. Do not open a public issue for it.

Say what is affected (package and version, or the address), what an attacker can do, and
how to reproduce it. We confirm that we received it, keep you informed while we fix it,
and credit you when the fix is out, if you wish.

Only the latest release of each package receives fixes.
